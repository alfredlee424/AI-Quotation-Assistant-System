正式身份／工程政策尚未完成，不能因本次兩次核對而呼叫 T47。[配號保留契約](批次配號保留契約與開發操作說明.md)要求未來**正式前置關卡全部通過後，才在第一次正式確認前保留整組號碼**；本批兩次核對不是那兩次正式確認。

## 2. 操作步驟

1. 在多明細配置草稿工作區選定來源工單草稿，逐項核對配置、成品數、需求帳本、共用／專屬範圍、條件及圖面依據，填寫操作人。
2. 先明確操作「批次逐張獨立金額試算」，取得全部子報價均有金額的目前試算。缺張、封存、來源不完整、未核對／待工程、任何子張阻擋或無批次總計時，不可建立可兩步核對文件。
3. 展開「整批固定內容與兩次核對（非正式、非開立）」，按 **「建立整批固定核對（非正式）」**。未按建立不產生固定文件；沒有有效試算就提示返回試算，不自動查價。
4. 逐張閱讀穩定品項／子報價識別、有序清單、成品數、完整專屬／共用文字、来源座標、配置、成本列、用量證據、精確金額及差額，並閱讀整批總計與正式待辦報告。
5. 按 **「記錄第一次整批核對（非正式）」**。只記錄第一筆事件，不同時執行第二次。
6. 同一位自填操作人重新核對同版內容，再按 **「記錄第二次整批核對（非正式、非開立）」**。第一次之前第二次按鈕不可用；完成後兩個按鈕均停用。
7. 可按「下載整批固定核對與歷史（非正式、非報價單）」。第零、第一、第二階段下載均包含相同固定內容及當時的核對歷史，不是可交付客戶的報價單。

**兩次限定同一操作人，並不假裝兩位工程人員簽核。** 自填姓名、依據與時間只是紀錄，不是身份驗證、權限授予或工程核准。所有正式報價／確認／保存能力始終關閉；沒有正式保存按鈕、保留請求或正式單號。

## 3. 固定內容與關卡報告

新文件完整保留：

- 整份來源批次原文、分類、行號、版本、工單歸屬與歷史；草稿來源及完整草稿版本。
- 原固定試算識別與摘要、全部有序子報價及穩定來源／配置對應，每張成品數。
- 全部專屬與適用共用描述、原文座標、需求處置、條件繼承、圖面紀錄與人工證據。
- 完整配置、成本輸入、單價／用量證據、逐列及逐張金額、折扣、稅、捨入差額與批次總計；不重新加總或重新查價。
- 操作人、金額／公式／描述／核對政策版本，以及固定關卡報告指紋。

關卡報告不是只數可報價旗標或使用 AI 信心值：

| 分類 | 本版意義 |
|---|---|
| 本次全部配置已算出 | 逐張固定摘要、計算狀態、成本列及無內部阻擋；不等於規則正式驗收 |
| 來源帳本人工處置 | 完整來源覆蓋、適用範圍、處置及未映射選配仍可追溯；不等於來源語意已核准 |
| 已登記條件／圖面 | 固定報告、紀錄及規則版本；沒有登記問題不表示所有工程需求已辨識 |
| 正式待辦 | 業務、工程、產品線、工序含價、身份授權、DBA、正式固定預覽／配號、同版原子保存八類始終待辦 |

原批次及每張的正式阻擋原樣保留，不能刪除後解鎖。金額算得出、手填姓名與依據，均不會讓正式待辦改成已核准。合成正例仍保留來源／正式阻擋及未映射規格，不假裝真實工單已通過 E03。

## 4. 兩步狀態、失效及重試

固定內容摘要與可演進的核對狀態摘要分開。建立一次才產生識別與時間；單純重繪／下載不更換識別、時間或 token。每次成功操作回傳新的深層複本，原輸入不變；只增加一筆含時間、操作人、前一狀態摘要、固定內容與目前試算摘要的非正式事件。

- 第一次必須使用建立時的 token；第二次必須使用第一次成功後的 token，不能直接第二步，也不能跨人、跨批、跨版本或跳步。
- 同一步重試採**明確拒絕**，不新增歷史。工作階段內鎖定與目前狀態摘要檢查防止兩個相同舊狀態並行重放；不宣稱跨程序或正式資料庫冪等保存。
- 每次展示、下載及核對都用呼叫端的**目前試算**重新驗證目前草稿／來源，不能只拿文件內嵌舊試算自行驗證。驗證不查主檔、不重跑公式。
- 來源原文／分類、草稿版本、數量、規格／每件項目數量、順序、共用條件、需求與依據、圖面、折扣、政策或操作人任一變更，舊文件及兩步 token 均失效。即使金額相同，重新試算的新識別也會使核對失效。
- 既有草稿保存與試算清除路徑同步撤銷核對控制器。觀察到上下文變更或文件篡改也撤銷；改回原值不能復活舊 token，必須明確建立新核對。
- 失敗不修改傳入狀態；UI 清掉舊成功文件、核對狀態與下載。單純錯序／錯 token 的核心操作可用原有效狀態重新操作，但不自動增加事件。
- 切換草稿不展示他批文件／token。外部圖面、主檔或公司政策變更不會被本工具自行監測；呼叫端須提供目前版本並走受控改版／失效流程，不支援把任意舊記憶體狀態回填當成目前版本。

程序內 HMAC 封印拒絕篡改後自行重算摘要，包括改正式能力旗標、刪子張、改金額、清空待辦或竄改歷史。這不是使用者簽章。控制器只在工作階段記憶體保存目前狀態摘要，不寫入 T47 registry、快照或其他資料庫。

**程序重啟／工作階段丟失後，須重新試算與建立核對。** 不支援下載檔重匯入、跨程序恢復或把此文件轉成正式文件。下載包含整份來源、內部成本、依據及工作階段核對 token，須按公司資料政策保管，不交客戶、不送模型。
