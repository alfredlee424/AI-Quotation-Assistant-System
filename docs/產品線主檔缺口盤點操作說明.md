# 產品線主檔缺口盤點：階段 5 準備批交付

## 1. 功能定位

2026-09-29 新增獨立「產品線主檔盤點」工作區，供 T22 的受控主檔盤點準備使用。

針對指定產品讀取類別、完整結構邊、規格、用量與部位定義，產出「資料問題」及「待人工核對」清單。**沒有查到資料問題，不表示產品已可報價，更不表示材料、工费或工程規則已核准。**

這是唯讀盤點工具，不是單品試算、多明細預覽、正式核准或資料修補程式。本批開發驗證只使用隔離測試資料，未盤點正式 ERP。

## 2. 操作步驟

1. 先由管理人員確認目前連線為允許查詢的受控副本或環境；正式驗收建議使用固定版本的靜態副本及唯讀帳號。
2. 頁面上方「工作區」選擇「產品線主檔盤點」。
3. 輸入一至三個產品代碼，以逗號分隔。預設 CMT1、MT、DT1 只是本計劃三產品線的代碼候選，須依實際環境確認，不按名稱自動猜測或建立產品。
4. 填寫「資料來源／受控副本版本（人工說明）」。此說明不會更換連線，也不會自動驗證副本版本。
5. 勾選「已確認允許唯讀查詢目前設定的資料庫」。
6. 按「執行唯讀主檔盤點」。未按執行前不讀主檔。
7. 查看逐產品摘要、資料問題、待人工核對事項與逐部位用量來源。
8. 需要保留結果時，下載「主檔缺口報告（非報價單）」。

若資料表、權限或連線有問題，顯示失敗且不會灌入範例、建立資料表或自動修補。重查前先清除舊結果；任一產品查詢失敗，整批不顯示部分成功結果。

## 3. 已支援的檢查

| 範圍 | 檢查項目 |
|---|---|
| 產品類別 | 是否唯一、是否屬報價產品、報價係數是否為正有限數值 |
| 結構 | 無結構、父子路徑不一致、跨產品、缺父節點、根部無法連接、重複子節點、子代碼與路徑不符、異常必選標記 |
| 規格 | 未連接結構的規格、同一路徑同代碼多筆、無規格葉節點、單價缺少／負值／非有限值 |
| 用量 | 未連接結構的規則、驅動部位缺少／多個／越界、重複規則、未知驅動代碼、用料量或裁切量無效 |
| 尺寸覆蓋 | 以驅動部位的全部可選代碼對照用量規則，不用材料自身代碼代替尺寸代碼 |
| 部位名稱 | 缺少、不唯一或空白的定義，列為待人工核對 |
| 工費 | 依現有工費部位代碼或名稱列出候選，另要求核對含工與重複收費政策 |

盤點採原始結構邊查詢，不只走目前可連接的遞迴選單，因此可看到未連接資料。規格採欄位資料列讀取，保留同代碼不同描述的重複資料，不以路徑字典靜默覆蓋。

## 4. 零值、缺值及現行按件政策

- 零用料量合法，會原樣保留；空用料量與零不相同。
- 裁切量須為正有限值；零、空值、負值都列問題，不補成一。
- 零採購單價與缺少單價分開，不以真假值判斷來補預設值。
- 有正價的父節點也檢查用量，不只檢查葉節點。
- 完全無規格但有子節點的容器不被當成缺少葉規格；此分類仍不是免費工序核准。
- 只有 CMT1 且符合既有程式按件清單、該路徑又完全沒有用量資料時，才標示「現行環式按件政策」。這只是程式現況，仍列待核對，不是本次新增的正式核准。
- 已有任何用量資料時，優先查驗驅動與尺寸覆蓋；不能以按件清單掩蓋缺少尺寸規則。
- MT、DT1 或其他產品不沿用環式按件政策；正價規格缺少用量資料就列缺口。
- 盤點會檢查已存在的全部用量規則，包括當前零價路徑上的舊規則；所以盤點問題數不等於某一筆實際配置的報價阻擋數。

## 5. 仍須業務／工程確認的事項

每條產品線均保留以下待核對項目，不因主檔結構完整就清除：

- 材料方案互斥、上下板組合與產品線政策版本。
- 腳架、配件、板件與尺寸的相容性。
- 線盒是否含開孔、貼面是否含工、撕膜是否含價及工費重複／漏計。
- 跨分支用量驅動在實際配置中是否會被啟用。
- 原文需求、圖面、幾何與正式工程核准。

工費候選只是名稱／代碼提示，不是已建立通用工序分類或含價規則。尺寸代碼覆蓋是逐表檢查，不會窮舉所有合法產品組合，也不能證明全部分支可一起啟用。

## 6. 來源、限制與資料保護

- 報告包含分析器版本、事業別、人工資料來源說明、讀取起訖時間、逐產品筆數與內容摘要。
- 來源摘要涵蓋本次讀到的資料及數值；資料列順序改變不影響摘要，單價或用量異動會改變摘要。
- 報告不輸出採購單價數值，只列正價、零價與無效狀態；仍包含內部產品名稱、規格代碼、路徑及報價係數，須依公司政策保管。
- 本次不讀客戶工單、歷史報價、正式快照或連線密碼，也不送模型服務。
- 每張主檔每產品最多讀取 20,000 筆，超過即拒絕，不能靜默截斷成完整報告。共用部位定義表先按事業別受限讀取，再只保留本次使用代碼。
- 使用單一查詢工作階段讀取每個產品的五張主檔，停用自動寫回；**不保證資料庫跨查詢的一致性快照**。正式驗收須採固定受控副本，不能把讀取時間或內容摘要當作資料庫版本鎖定。
- 改變產品輸入、來源說明或撤回查詢同意，畫面會清除舊結果。主檔本身變動不會自動重查；保留的報告只代表當時讀到的內容。
- 不修改單品、多明細、來源工單或人工核對狀態；下載檔不支援套用配置或匯入正式報價。
