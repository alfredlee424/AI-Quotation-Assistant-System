# 共用條件與局部例外核對：階段 4 第一批交付

## 1. 功能與安全界線

2026-09-29 在「多明細配置草稿」加入「共用條件、局部例外與否定核對」。

可人工指定來源需求、作用明細、正式部位及局部例外，保存依據與歷史，顯示繼承、衝突及配置不符。**人工核對不是工程核准，也不代表整單需求、用量或成本完整。**

本批不計價、不保存正式報價、不解除既有來源阻擋、不自動解析工單條件、不呼叫模型推論作用範圍。既有單品入口仍維持原流程；新增保護作用於多明細配置入口。

## 2. 操作方式

1. 從工單核對結果轉接多明細草稿，填寫操作人。
2. 展開「共用條件、局部例外與否定核對」，勾選「編輯共用條件與局部例外」。
3. 選擇新增條件，或選取既有紀錄重新核對。
4. 指定條件類型、要求狀態與作用範圍。
5. 引用工單來源需求；同一來源片段可支持不同條件，但仍須另外完成原子需求拆分與語意核對。
6. 如為局部例外，明確勾選要覆蓋的較廣範圍條件。
7. 需要驗證配置時，勾選「查詢並設定條件正式部位（唯讀主檔）」並逐筆選擇部位。
8. 填寫依據識別／版本與核對理由，按「保存條件核對紀錄（非工程核准）」。

新增或重新核對都須重新填寫依據及理由。撤回條件也須填理由，撤回後保留條件、原有依據與操作歷史，不刪來源需求。

## 3. 範圍與例外

| 範圍 | 行為 |
|---|---|
| 全單 | 明確包含目前全部活動明細；保存當下的穩定識別清單 |
| 人工角色群組 | 填寫角色名稱並明確選取明細；不依名稱、尺寸或文字自動分組 |
| 單筆產品 | 只能選取一筆活動明細 |
| 指定部位 | 每個條件的每筆目標可綁一個正式部位；需要多個部位時分開建立條件 |

- 群組名稱只是本筆條件的人工說明，不是會動態擴展成員的角色主檔。
- 新增明細不會默默繼承全單／群組條件；全單成員改變會要求重新核對，原群組維持既定清單。
- 例外只能引用同類型、已核對且較廣範圍的條件，作用明細必須完全包含在被引用範圍內。
- 單筆可以覆蓋群組或全單；群組可以覆蓋全單。同層條件不能互相覆蓋。
- 不因範圍較小就自動覆蓋；沒有明確引用時，相反要求仍列衝突。
- 支援全單→群組→單筆的明確繼承鏈，可查看原始繼承與被覆蓋條件識別。
- 同層或未明確覆蓋的不同要求、不同內容文字採保守衝突判定，不採最後一句勝出；本批不判斷兩段不同文字是否語意相同。

## 4. 否定與位置條件

「未指定、明確需要、明確不要、不適用」分開保存。没有紀錄也不等於明確不要。

條件類型分成桌面開孔、腳板走線孔、桌下走線、桌面孔位及隔板位置。桌面無孔的例外不會覆蓋桌下走線或腳板孔；同一路徑在不同明細中也分開驗證。

正式部位綁定契約：

- 必須先指定該筆產品，再從其現行合法部位清單選擇；部位不必已選規格。
- 綁定作用於該完整部位及其子樹，不能以過廣的桌面／腳架根部位代替真正孔位。
- **程式只驗證路徑合法性，不會判斷「這個路徑是否真的是桌面孔」。** 操作者必須核對語意；未建立產品線核准映射前不可視為正式工程規則。
- 未綁定可保存人工紀錄，但顯示待核對，不能推論配置已符合。
- 明確需要但未選配會提示缺項，不自動加入；位置需要額外圖面／基準驗證，即使選配已存在仍顯示待核對。
- 明確不要或不適用的部位若已選配，顯示衝突，不會自動刪除。
- 多明細手動配置及 AI 整批提案，都在既有必選解析之後檢查禁止部位。即使必選規則自動啟用尚未選定規格的部位，也會原子拒絕。
- 桌面孔位要求與桌面開孔未指定、禁止、不適用或衝突時，會提出具體相依問題；腳板孔與桌下走線不被當成桌面孔的替代依據。

## 5. 版本與重新核對

- 每次條件保存／撤回只增加一個整單修訂版與一筆稽核事件；不改配置、來源或既有阻擋。
- 相關配置、來源需求、全單成員或例外父條件改變後，核對紀錄失效；重新排序不改變作用明細。
- 封存後恢復明細、或將配置改回原值，都不會自動恢復核對狀態。
- 失效例外不再壓掉父條件；失效的否定紀錄仍保守參與配置攔截，不能藉版本失效繞過限制。
- 更換已綁定條件的產品前，須先有理由地撤回條件，修改產品後重新建立正式部位對照。
- 修改父條件須重新核對引用它的局部例外；撤回父條件不會連帶刪除例外。
- 來源工單批次或分類版本變更時沿用既有保護，須重新轉接，不自動重綁條件。
- 條件與需求帳本是不同核對紀錄；保存條件不會自動處置來源需求或結案 AI 問題。

資料採加法式草稿欄位及独立條件規則版本，保存在工作階段與既有草稿下載中，沒有資料庫遷移或正式快照改版。下載可供追溯，仍不支援重新匯入工作階段。原文与依據可能含商業資訊，應依公司資料政策保存。
