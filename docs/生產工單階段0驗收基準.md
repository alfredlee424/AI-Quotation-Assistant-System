## 3. 樣本與標註規則

### 3.1 去識別化範圍

- 客戶名稱替換為測試客戶 A 至 H；日期與單號替換為合成值，樓層亦已替換。
- 保留九碼日期異常，作為來源品質問題，不沿用真實單號。
- 保留尺寸、數量、色號、錯字、加工簡稱及缺圖情境，因為這些是測試目標。
- 樣本不讀取原始私人工單、日誌或 ERP 主檔，不包含原客戶到測試客戶的對照表。
- 這是去識別化，不代表技術規格已完全去敏；若要公開散布，仍須依公司資料政策審核。

### 3.2 事實、候選與未知分開保存

| 標註層級 | 意義 | 範例 |
|---|---|---|
| 原文直接陳述 | 原文確實寫出條件，但不代表已有合法規格與成本 | 面無孔、桌下走線、再鎖鋁合金 |
| 候選解讀 | 人工依文字提出的拆分、數量或範圍預期，仍需業務核准 | 行尾數量、每件孔數、主席／列席配置 |
| 尚未釐清 | 不能從原文安全定案 | 台尺換算、2.5 鋁、船型曲線、實內尺寸 |

所有案例整體都保留「待業務／工程審閱」及空白核准證據。接受改善計劃只代表接受工作範圍，不等於核准這些技術語意。

資料結構為不可變候選資料；測試不會自動補單位、正式代碼、規格、用量或價格。未來正式核准須記錄核准人、依據及版本，並同步調整候選契約，不能只刪除未核准檢查。

### 3.3 計數與套組限制

- 環式 A：候選四筆配置、11 件產品、9 組線盒。
- 環式 B：候選四筆配置、7 件產品、7 組線盒、7 個圓孔。
- 環式 C：候選四筆配置、9 件產品、15 個圓孔。
- 線盒開孔不與另列的圓孔混算；沒有提供的配件數量保留未知。
- 餐桌的三筆來源項目不等於三張成品桌；不設定成品桌總數。
- 四分之一圓、二分之一圓、括號分片數不直接轉換成產品數量。

## 4. 業務／工程審閱清單

下列所有項目目前皆待核准；詳細問題、來源引用及所需解鎖證據保存在[候選樣本](../test/work_order_fixtures.py)。

| 樣本 | 候選解讀 | 待業務確認 | 待工程確認 |
|---|---|---|---|
| 環式 A | 四筆配置；彎角無孔但保留桌下走線 | 行尾數量、色號與含價工序 | 置物板尺寸／數量／範圍、靠單定位、線盒是否含挖孔 |
| 環式 B | 主席／彎角與列席分組，每件線盒及圓孔各一 | 台尺慣例、數量語意、材料簡稱 | 位置基準、腳板禁孔及貼面／噴塗部位 |
| 環式 C | 四筆配置，括號孔數為每件候選 | 台尺、括號孔數語意 | 孔位圖、格的定義／間距及走縣錯字修正 |
| 會議 D | 單件長方斜刀桌；來源單號有合成異常 | 單號、單位、數量、材質 | 基材板厚、噴黑部位、腳架及線盒規格 |
| 會議 E | 總尺寸、分片尺寸、行尾成品數分離 | 數量層級及原始尺寸矛盾 | 船型曲線、拼接、支撐、線槽圖與用量 |
| 會議 F | 船型桌與分片構成分离；只在中桶挖孔 | 台尺、材質簡稱及線盒數量 | 幾何、拼接、中桶孔數／尺寸及正式用量 |
| 餐桌 G | 主桌與腳座配套，另有庫存面改裝 | 庫存面用途、成本政策、2.5 鋁單位 | 假厚結構、補強材料、腳座適配及裝配順序 |
| 餐桌 H | 主桌、轉盤、支撐及腳座為多層組件 | 分片數、套組數量及尺寸單位 | 實內尺寸、公差、承重、模板計費與假厚／封邊用量 |

核准流程：

1. 核對對應的來源片段與候選解讀，不一次勾選整張單為「全部正確」。
2. 記錄仍待補充的圖面、量測、主檔或成本依據。
3. 有歧義的規則必須保留未知或提出更正，不能以模型信心取代確認。
4. 有核准依據後，才更新對應樣本預期與版本；未解決條件繼續作為拒絕案例。
5. 第一版尚不支援的非標核價，即使人工理解需求，也不因此允許正式報價。

- 正式價格及模型品質仍需後續受控環境驗收；本次未連線正式 ERP 或實際模型。
