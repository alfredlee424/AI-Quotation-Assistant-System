# 工單核對去識別化摘要操作說明

## 1. 用途與界線

本批接續 T45 的需求覆蓋、阻擋原因與人工修正可觀測性，返回工單核對工作流程；不再新增檢查程序監督封套。

只將目前工作階段的來源工單與配置草稿轉為**固定分類、計數及非正式警語**。不查主檔、不計價、不配號、不保存正式報價，也不修改草稿或寫入監測日誌。這是開發摘要，不是持久稽核、使用者簽章、權限或正式核准證據。

## 2. 操作

1. 在既有工單核對工作區匯入並核對來源，轉接一張工單為多明細配置草稿。
2. 填寫「操作人（自填紀錄，非核准簽章）」。此值只用於既有入口核對，不輸出至摘要。
3. 展開「工單核對去識別化摘要（非正式）」，勾選「顯示工單核對去識別化摘要（非正式）」。只展開區塊不會產生摘要。
4. 檢視中文計數表及完整結構化摘要；需要逐筆原因時，回到既有需求／條件／圖面核對區，而不是在摘要加入客戶原文。
5. 可按「下載工單核對去識別化摘要（非正式）」。下載名稱固定，不含來源單號、草稿識別或人名。
6. 取消勾選即隱藏摘要及下載。開啟期間每次重繪都以目前記憶體來源重新核對，不快取舊成功摘要，也不重新查主檔。

來源改版、品項缺漏、封存、跨單、來源座標不一致或不相容版本，整批拒絕摘要。手動空白／單品轉接草稿不推定已有工單來源。操作人清空或產生／序列化失敗時，不展示前次摘要或下載；錯誤使用固定文字，不回顯原始例外內容。

## 3. 計數如何判讀

| 分類 | 意義 | 不可推論 |
|---|---|---|
| 來源品項 | 一張來源工單的完整配置品項數；四品項／11 件仍為四筆 | 不代表已配發四張正式單號 |
| 來源帳本覆蓋 | 非空來源行是否有完整文字區間紀錄，另列未覆蓋行數 | 不是語意、選配、含價或工程完整性 |
| 需求狀態 | 未核對、已記錄、待工程、失效分開計數；拆分封存紀錄另列 | 已記錄不等於已核准；封存父紀錄不重算活動需求 |
| 對照與未映射選配 | 既有需求對照筆數及沒有有效已記錄對照的選配數 | 未映射不代表新增價格；對照存在不代表正式主檔仍有效 |
| 條件問題 | 固定問題分類及投影數；撤回紀錄保留計數但不算活動問題 | 同一條件套四筆可形成四個問題投影，不能當四個獨立根因 |
| 圖面依賴 | 缺圖、已記錄、失效的紀錄數；問題投影另列 | 零紀錄／零問題不表示已辨識全部缺圖需求 |
| 問題紀錄 | 未結案／已結案狀態，失效結案重新列未結案 | 配置中的文字問題投影另計，不與問題紀錄相加去重 |
| 展開核對 | 待確認數量、含問題子張數及既有展開問題投影 | 核對完成仍不代表已計價或可以正式報價 |
| 草稿修改 | 需求、條件、圖面操作及其他操作分類的歷史事件數 | 不驗證歷史真實性、不計操作人次；重繪不新增事件 |
| 來源分類修正 | 此草稿保留的相關來源分類修正次數 | 不等於全檔所有工單修正數 |

各分類刻意保留自身分母與投影語意，**不提供相加的總阻擋數、完成百分比或可正式報價燈號**。未登記的問題不可能僅靠計數自動發現。

業務、工程、產品線、含價、身份授權、DBA、正式固定預覽／配號及正式原子保存八類關卡始終待辦。無價格檢查、語意完整認證或正式確認／保存能力，不因所有已登記紀錄都完成而解鎖。

## 4. 資料最小化與使用限制

- 使用明確欄位投影；不輸出來源原文、工單號、批次／明細／需求／圖面識別、產品代碼、路徑、操作人、理由、依據、時間、單價、成本或金額。
- 不輸出原始內容雜湊，避免把穩定摘要誤當來源認證，或用於跨報告連結來源身份。
- 未知狀態或問題分類拒絕，不把原值當成輸出欄位；未知歷史操作只算「其他」，不輸出原操作值或內容。
- 所有計數仍是內部營運資訊，沒有差分隱私或不可重新識別保證。下載仍應依公司資料政策保管，不自動傳模型、外部監控或客戶。
- 摘要無來源識別、簽章或持久事件編號，不能用來追溯某份正式工單、驗證外部文件、重建歷史或認證來源最新性。原始完整證據仍留在既有受控核對流程。
- 只反映呼叫端提供的目前記憶體；不監看外部來源、主檔、圖面或公司政策變更。若外部狀態變更，須先更新來源及草稿，再重新核對。
- 不提供下載匯入或正式轉型入口；直接更改摘要欄位不能授予正式能力。
