**存的是去識別開發檢查報告，不是報價快照、正式稽核或備份。** 原受控執行、離線驗證、四種檢查服務、配號／保存／查閱及應用均未修改。T45／T43／T31、正式 E01–E09 與業務／工程／身份／DBA 核准仍待。

命令不接受外部報告、標準輸入報告、自填檢查退出碼、自訂程式、覆寫、修復或自動重試選項。檢查完整完成但發現差異時仍可保存差異報告，退出碼維持 1；不能把「已存檔」當成檢查通過。

## 2. 目的目錄與操作

使用[指定虛擬環境](../venv/)；目前只支援 POSIX，實測 macOS。Windows 在執行檢查前拒絕，未驗收 Linux、網路檔案系統或其他資料庫 runtime。

操作者須先準備：

1. 經確認允許唯讀檢查的既存隔離開發副本。來源規則與[受控執行操作說明](開發檢查受控執行操作說明.md)相同；不指向正式 ERP。
2. **工作區外的既存私有目錄**，擁有者必須為目前有效使用者，群組及其他人的權限全部關閉；一般採 0700。程式不建立或修改目錄權限，不接受末端符號連結或私人環境檔名稱。
3. 新的報告檔名：英數字開頭，主名 1–80 個英數字、底線或連字號，副檔名固定小寫 JSON；不含路徑分隔、空白、點開頭或跳脫片段。目的檔必須不存在，既存一般檔、目錄、符號連結、斷鏈及硬連結一律拒絕。

## 3. 原子發布契約

[目錄前置檢查](../development_inspection_archive.py:54)以不跟隨末端符號連結的方式開啟目錄，核對實際擁有者／權限後，整次保持同一目錄描述符。目錄不支援同步時拒絕，不降級為直接覆寫。

[文件重驗](../development_inspection_archive.py:89)拒絕未知外層欄位／版本、非標準第四版執行識別、警語／能力旗標異動、操作／狀態／退出碼矛盾；內嵌文件重新通過既有嚴格離線契約。完整序列化後才建立暫存檔。外層上限 128 KiB，內嵌報告仍受原驗證器 64 KiB 限制，超量拒絕，不截斷。

[發布順序](../development_inspection_archive.py:115)：

1. 在已開啟的目的目錄排他建立隨機暫存檔，權限固定 0600。
2. 迴圈處理短寫入，寫滿完整位元組並同步檔案；任何零寫入／磁碟錯誤均拒絕。
3. 以同目錄硬連結原子發布目的名稱，目的名稱已存在就失敗，**不用可覆寫的重新命名**。前置檢查後有另一程序搶先建立目的檔也不會覆寫。
4. 移除本次暫存名稱，同步目錄；成功後才輸出回條。

目的名稱對一般讀者只有「不存在」或「完整內容」兩種狀態，不會看見半份報告。此保證以可信本機、同目錄硬連結及檔案系統原子語意為前提，不涵蓋同 UID 惡意程序或管理員直接篡改內容。

## 4. 文件、回條及失敗語意

目的檔完整保留[原受控封套](../development_inspection_run.py:142)，包含本次執行識別、完整內嵌檢查、版本、所有警語及關閉的正式能力旗標；不是只存摘要或成功旗標。未新增來源路徑、原始身份、單號、客戶原文、成本或任意 SQL。

標準輸出的[新版本回條](../development_inspection_archive.py:158)含執行識別、操作／狀態、原檢查退出碼、完整檔案位元組數及 SHA-256、發布狀態與警語；不回顯目的路徑或自填檔名。雜湊涵蓋檔案尾端換行，可用來比對位元組，但不是簽章或權限憑證。回條的保存／接收也可能失敗，不是第二個原子檔案。

| 退出碼 | 意義 |
|---|---|
| 0 | 本次無差異報告完整發布且回條輸出成功；或僅求助成功 |
| 1 | 本次完整差異報告已發布；仍須調查差異，不代表通過 |
| 2 | 參數／來源／目的拒絕，未啟動檢查；包含目的檔已存在 |
| 3 | 平台、程序、驗證、存檔、同步或回條輸出失敗；不提供成功結論 |
| 130 | 可捕捉中止；不得假設目的檔一定不存在 |

**發布後才失敗，不刪除目的檔假装回滾。** 目錄同步、移除暫存名稱、關閉描述符、回條寫出／刷新或人工中止，都可能發生在完整目的檔已可見之後。因此 3／130 或收不到回條時，操作者須人工核對目的檔，不可自動覆寫、刪除或把重跑新識別視為原次成功。既存檔重試拒絕，即使內容相同也不宣稱冪等成功。

可捕捉失敗會嘗試清理本次暫存名稱；不可捕捉硬中止、主機故障或清理本身失敗仍可留下暫存檔。不掃描或自動刪除其他檔案，**暫存檔不是有效發布證據**，須由可信人員確認沒有活動程序後依保留政策处理。即使暫存檔包含完整內容，也不能自行改名宣稱檢查成功。

## 5. 安全與驗收界線

- 目錄描述符可防止後續路徑重新解析導向另一個目錄；若目錄被搬走，檔案仍發布在原開啟目錄，而不是新同名目錄。祖先路徑、ACL、同 UID 程序、解譯器與已安裝套件仍須可信，0700 模式檢查不是完整 ACL／權限稽核或 OS 沙箱。
- 來源身份與權威性仍未認證；來源路徑核對到實際讀取間的替換风险與原入口相同。執行識別沒有外部來源登錄，不證明最新性、停寫、跨庫同一復原點或備份可用性。
- 檔案與目錄同步是發布協定的一部分，**不是主機斷電／儲存控制器耐久保證**；沒有跨檔案系統或遠端檔案系統認證。檔案系統呼叫可能阻塞，原程序期限不是整次存檔的硬即時 SLA。
- 自洽偽造、合法一致重寫或共同過期仍可能通過；存檔不替來源加簽、不防重放、不恢復配號。
- 沒有報告重新匯入、正式稽核資料庫、保留排程、來源認證或備份恢復授權；保管／加密／ACL／保留期限、可信外部歷史及 DBA／部署核准仍待。
