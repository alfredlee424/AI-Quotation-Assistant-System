# 工單尺寸、數量與簡寫診斷：階段 3 第一批交付

## 1. 功能定位與入口

2026-09-24 在「生產工單核對」工作區新增「尺寸、數量與簡寫診斷（唯讀，不套用配置）」。

貼上並建立核對草稿後，展開診斷區即可查看原文位置、數值、單位、用途候選、數量範圍、可確定的公分換算及待確認提示，也可下載診斷結果。

**此功能不改寫來源、不更改草稿配置、不查主檔、不呼叫模型、不計價，也不核准需求。**

## 2. 明確單位的正規化

| 輸入例子 | 診斷結果 |
|---|---|
| 桌面 600mm×1800mm | 正規化為 60×180 公分 |
| 桌面 600毫米×180公分 | 分別換算後為 60×180 公分 |
| 桌面 60×180cm | 相同尺寸鏈的明確單位套用至未重複標示的軸，結果為 60×180 公分 |
| 桌面 60.125cm×180.5cm | 保留精確小數，不擅自取整 |
| 桌面 60×180 或 1200×600 | 單位未知，不依大小猜公分／毫米 |
| 9尺圓、12台尺圓 | 保留尺數，提示台尺定義、換算與取整慣例待核准 |

目前只支援明確的公分／毫米正規化。沒有全單預設單位，也不把本行單位自動套用到其他行。全形數字、乘號及單位字母可以辨識，顯示及座標仍對應原始文字。

正規化成功只代表數值換算可確定，**不代表尺寸用途、產品規格或加工方法已確認**。

## 3. 分開顯示尺寸角色與數量層級

診斷會嘗試區分：

- 桌面尺寸候選、線盒／五金尺寸候選。
- 圓形直徑、孔徑、適用桌面尺數與鋁件尺寸候選。
- 板材實厚候選與假厚；假厚另外提示不能當成整片實厚板。
- 行尾來源明細數量、每件配件數、部件數及孔數。
- 括號分片尺寸與片數候選。
- 四分之一圓、二分之一圓等形狀比例。

例：「平直70×140------4 面2孔6公分圓孔」會分開顯示來源明細數量候選 4、孔數候選 2、孔徑 6 公分及桌面尺寸。**不會自行相乘成整單孔數，也不將孔數當成桌數。**

「每桌」等明確字樣可提供每件用量的範圍線索；其餘省略寫法保持待確認。用途及數量範圍仍是規則式候選，不取代使用者核對或完整語意分析。

## 4. 分片與幾何條件

- 「5×14（5×7×2）」保留總尺寸，括號前兩項列為分片尺寸候選、末項列為片數候選；要求確認括號語意。
- 「120cm×180cm×2cm」保留三軸長度，不將最後一軸當片數。
- 超過三軸的尺寸鏈列為不支援，不能截斷後顯示為有效規格；同一行後方的其他尺寸仍獨立診斷。
- 「1/4圓」「1/2圓」只表示分片比例，不轉成 0.25 或 0.5 件產品。
- 「120−20＝100」保留為幾何算式並要求說明各數值用途，不能直接由算式決定船型弧度。

總尺寸與分片的比較只做必要的外框容納檢查。若單位可換算，先以相同單位比較；兩者都沒標單位時，只能給出「若採相同單位」的條件式警告。

例如「20×360（120×180×2）」會指出可能矛盾，**不會自行把 20 改為 120**。通過容納檢查也不代表拼接、曲線、承重或用量正確。

## 5. 簡寫與缺漏提示

| 原文情境 | 提示行為 |
|---|---|
| 2.5鋁 | 單位或用途不明，不補成尺、公分或型號 |
| 走縣／置物版／船形 | 提出走線／置物板／船型的詞彙候選，不改寫原文，也不丟掉否定條件 |
| 照圖、靠單、如圖面 | 要求具體圖面或訂單附圖 |
| 實內尺寸 | 要求實測依據，不能用外框或鋁件尺數代替 |
| 零尺寸、小數件數或無效片數 | 提示重新確認，不當成合法產品用量 |

目前詞彙提示是明列的診斷規則，**不是已經業務核准的產品別／部位別詞彙字典**。色號、品牌與材質簡稱尚未自動對應正式規格。

## 6. 資料與安全界線

- 每個數值發現與問題提示保留原始行識別、行號、起訖字元與原文片段。
- 診斷文件綁定批次識別、來源摘要、分類版本及診斷器版本。
- 相同批次與內容重複診斷結果一致；不修改工單分類、產品數量或多明細配置。
- 所有診斷文件都標示不能套用配置、不能正式報價。
- 未命中診斷規則不等於沒有問題。未支援的單位、語法或用途仍須人工檢查。
- 支援的數字長度有界限，異常或過長數字不局部截取成有效尺寸；長串空白與破折號等輸入有對應回歸案例。
- 下載結果包含業務原文片段，請依公司資料政策保管；目前不提供診斷檔匯入或直接轉正式規格。

本批沒有修改原本單品聊天的尺寸解析規則；診斷器是工單核對的独立入口。
