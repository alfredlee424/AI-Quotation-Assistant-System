# 工單數值候選受控套用：階段 3 第二批交付

## 1. 目的與界線

2026-09-30 在「多明細配置草稿」加入「工單數值候選核對與受控套用」。

原本[數值診斷](工單尺寸數量診斷操作說明.md)保持唯讀。本次新增獨立流程，將目前工單來源重新診斷後，由操作者確認數值用途、單位及對應明細，先產生固定配置差異，再明確套用。

**人工數值確認只代表配置輸入，不代表業務／工程核准，也不解除正式報價關卡。** 本批不自動修正原文、估算非標、換算台尺、產生材料用量或自動結案來源需求。

## 2. 進入條件

- 必須是由生產工單轉接的多明細草稿，且目前工單批次、來源摘要與分類版本仍一致。
- 目標必須是本草稿的活動明細，並有該工單的直接來源行。
- 請先在原有合法選配區明確指定產品類別。新功能不採預設產品。
- 同一來源行若對應多筆活動明細，須先釐清分配；不能將同一件數自動套給多筆產品。
- 空白手建明細、單品轉接、封存明細或其他工單的候選不能使用此入口移用數值。

原文或切分有誤時，請回工單核對修正並重新轉接，不以數值套用掩蓋來源錯誤。

## 3. 行尾候選確認為成品數量

1. 選擇草稿，填寫操作人。
2. 展開「工單數值候選核對與受控套用」。
3. 選擇「數值套用目標明細」與「行尾候選確認為成品數量」。
4. 核對原文、來源行號、候選類型及診斷警告。
5. 填寫「數值語意／單位確認依據識別與版本」及具體確認內容。
6. 確認該數量是此明細的成品數，而不是孔數、每件配件數、材料片數或整單工序數，勾選人工確認。
7. 按「產生數值套用差異（不修改草稿）」。
8. 檢查固定提案的目標、來源、依據及套用前後配置，再按「套用已核對數值差異（非工程核准）」。

只接受解析為有效正整數的行尾來源數量；零、小數、分數或異常後綴不能截取前面的整數來使用。

例如「桌面600mm×1200mm-----2 面2孔6公分圓孔」可在人工確認後將行尾 2 套為成品數。孔數 2 與孔徑 6 公分仍是不同需求，不會相乘或代入成品數量。

行尾數量也可能是桌面、腳座或改裝項目的數量，系統不能自行判斷成品角色。若角色未釐清，應停止套用；原有來源與工程阻擋始終保留。

## 4. 兩軸候選確認為桌面尺寸

本批僅支援環式產品的桌面尺寸部位。其他產品、圓形直徑、孔徑、配件尺寸、實厚、假厚、分片及三軸尺寸仍使用原本人工核對，不跨產品沿用此映射。

1. 將「數值套用類型」改為「兩軸候選確認為桌面尺寸」。
2. 選擇對應來源尺寸候選。
3. 確認來源尺寸單位：原文明確為公分／毫米時可以使用原文單位；原文未標單位時，必須依實際依據人工補充公分或毫米。
4. 確認主檔尺寸單位：主檔若只有「60×120」，也不能默認為公分，須另行人工確認。
5. 明確選擇兩軸依原文順序，或經人工確認後交換順序。
6. 勾選「查詢目標明細合法桌面尺寸（唯讀主檔）」，明確選取目標規格。
7. 填寫確認依據、用途／單位／軸順序的具體內容，勾選人工確認。
8. 先產生固定差異，核對後再明確套用。

### 精確比對原則

| 情境 | 行為 |
|---|---|
| 600毫米×1200毫米 → 主檔60×120，人工確認主檔為公分 | 精確換算後可提出差異 |
| 600×1200 未寫單位 | 未人工補充單位時阻擋，不依大小猜毫米 |
| 120公分×60公分 → 主檔60×120 | 必須明確確認交換兩軸，不能自動視為相同方向 |
| 60.01公分×120公分 → 主檔60×120 | 不完全相等，拒絕；不取整或近似匹配 |
| 原文為毫米，人工改選公分 | 與明確原文衝突，拒絕覆蓋 |
| 原文為台尺／尺 | 拒絕，不允許以選公分或毫米繞過未核准台尺政策 |
| 主檔描述混入特製文字或三軸尺寸 | 拒絕，不擷取局部數字假裝是標準兩軸尺寸 |
| 同行有兩組桌面尺寸、分片、幾何算式或總／分片尺寸矛盾 | 保留阻擋，不採第一組、最後一組或自行補字 |

混合但明確的公分與毫米會逐軸精確換算。不使用全單預設單位，不把上一筆人工單位套用到其他來源或其他主檔。人工確認單位的依據只適用於本次明細與候選，不是公司正式單位政策。

診斷用途只是保守候選；複雜描述若沒有桌面尺寸候選，不以其他類型候選替代，仍須回到人工來源核對。

## 5. 固定差異、套用與失效

- 產生差異不修改草稿，會顯示來源座標、原文、正規化值、人工單位、軸順序、合法規格及配置前後差異。
- 表單輸入變更不會偷偷改寫既有固定提案。修改輸入後須重新產生差異；套用按鈕始終以畫面顯示的固定提案目標與依據為準。
- 草稿、來源、操作人、診斷器或套用規則版本改變，舊提案失效。
- 顯示既有提案時只驗證固定內容，不查主檔；勾選的尺寸選單區仍會作明確開啟的唯讀主檔查詢。
- 套用前重新檢查合法選單與固定差異。主檔、規格描述或自動必選變更後，若與操作者看過的提案不一致，整次拒絕並要求重新產生。
- 不保證跨查詢的資料庫一致性快照，也不輪詢外部主檔；這不是鎖價或正式固定報價。
- 尺寸只變更指定明細的桌面尺寸規格，保留原每件項目數量；成品數套用不把配件或分片數帶入。
- 仍經原有配置核心與否定條件驗證，不另開可以繞過必選／禁止部位的入口。
- 一次成功套用只增加一次整單與目標明細版本，失敗不留下部分配置。
- 成品數與尺寸分次核對，第一筆套用後須基於新版本重新產生下一筆差異。
- 配置變更仍會使相關需求證據、圖面核對、內部試算及關聯演練失效；不因來源數值已套入就自動將需求列為已處置。

## 6. 歷史與資料保護

成功套用會在草稿操作歷史保存操作者、時間、來源數值發現、完整來源座標、人工依據、診斷／套用版本、正規化與單位紀錄、主檔摘要及配置差異。

歷史用於追溯，不是持續有效的工程核准。更改後的配置是否仍符合來源，要由需求核對與工程流程重新確認。原始工單、其他明細及單品報價工作區不被覆寫。

人工依據與數值確認歷史不加入模型上下文，不提供模型可呼叫的受控套用工具；圖面及數值原文可能含商業資料，下載草稿須依公司政策保管。草稿仍只保存在工作階段與下載檔，本批不新增正式資料庫保存。
